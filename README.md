# iq-setters

Marketing site for IQ Setters — a lead and follow-up workspace for real estate teams.

Static site: open `index.html` in a browser, or serve the folder with any static file server.

- `index.html` — page markup
- `styles.css`, `home-sections.css` — styles
- `app.js` — navigation and GSAP scroll/illustration motion
- `assets/` — images, icons and fonts
